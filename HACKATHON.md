# Cal Poly Vibe Coding AI Hackathon

Graphu is a new build based on the earlier Graphu idea. The team can reference the product specification and must write any submitted project code within the event window. Keep normal Git history and credit any external resources in the submission.

All times are Pacific, November 2026.

| Time | Deliverable |
|---|---|
| Fri Nov 13, 5 PM | Build window opens |
| Sat Nov 14, 2 PM | Submit a project link showing work so far |
| Sat Nov 14, 8 PM | Confirm Sunday participation and provide the live link |
| Sun Nov 15, 10 AM | Check in with the judging room volunteer |
| Sun Nov 15, noon | Submit the live link, project link, description and AI credits. Freeze features and fixes |
| Sun Nov 15, 1–3 PM | Room judging |

The team may enter one optional challenge. Submit an accessible demo-video link under two minutes if entering. Best Use of AI is a candidate for the team to decide. Check Discord and the [official participant guide](https://cpvc-ai-hackathon-guide.vercel.app/#due) for changes. Check judging access before submitting the private repository link.

## Team workflow

Clone the repository, branch from `main`, and open a pull request after running the tests. Keep secrets, local databases, and actual course documents out of Git. For a demo, show the PDF import, review decisions and click through to a source quote. Use sample notes for a repeatable walkthrough of the review and provenance steps without a key.

## Submission credits

- OpenAI Codex generated the initial project scaffold, implementation, tests and docs during the build window.
- OpenAI Responses API proposes concepts and relationships from page text when live extraction is enabled.
- React, TypeScript and Vite provide the frontend and build tools.
- FastAPI, Uvicorn, Starlette and Pydantic provide the backend and request validation. pypdf extracts PDF text. SQLite stores proposals and decisions. HTTPX supports API tests.
- The built-in hash-table notes and Graphu icon were created for this repository. Add credits for any additional tools, media, datasets or assets before submitting.
