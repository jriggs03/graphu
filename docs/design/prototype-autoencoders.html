How Graphu built this

  1. Read each slide's text and keep its page number.
  2. Extract: Claude proposes concepts and links, each with a quote.
  3. Check: Rust keeps a quote only if it's really on that slide.
  4. Connect: link concepts when one slide uses another's name.
  5. Rank: PageRank on dependent → prerequisite sets circle size.
  6. Review: you approve before anything is final.
